# CLUBIX - Application Mobile de Gestion des Clubs Universitaires

CLUBIX est une application mobile développée pour simplifier la gestion des membres, des inscriptions et des événements au sein des clubs universitaires.

##  Fonctionnalités principales
- **Gestion des utilisateurs :** Inscriptions, demandes d'adhésion et suivi des membres.
- **Gestion des événements :** Création, publication et suivi des événements du club.
- **Architecture Multi-rôles :** Espace dédié pour Administrateurs, Membres et Visiteurs.
- **Tableau de bord (Dashboard) :** Statistiques et vue d'ensemble des activités du club.

##  Stack Technique
- **Mobile Front-end :** React Native CLI, TypeScript, Android Studio
- **Back-end :** Node.js, Express.js (Architecture Client-Serveur / API REST)
- **Base de données :** Oracle SQL
- **Gestion & Méthodologie :** Conception UML, méthode Agile/Scrum, Git/GitHub, Trello
